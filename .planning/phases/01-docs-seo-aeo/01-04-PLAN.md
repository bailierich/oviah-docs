<objective>
Add the two AEO discovery endpoints — `llms.txt` (summary) and `llms-full.txt` (full body) — as dynamic Next.js route handlers.

Purpose:
- `llms.txt` is the emerging convention (analogous to `robots.txt`) telling AI agents where the canonical content is and what it covers. Perplexity already crawls it; ChatGPT, Claude, and other agents are following.
- `llms-full.txt` is the same content but with full article body text inlined, so AI agents that prefer single-document ingestion can pull the entire help center in one request.
- Both are dynamic route handlers (NOT static files) so they update as articles are added — no rebuild step required for new content.

Output:
- `lib/content.js` — extended with two new exports: `mdxBodyToText(raw)` (strip JSX wrappers) and `getAllArticlesWithBody()` returning `{ frontmatter, content, bodyText, slug, category }[]`.
- `app/llms.txt/route.js` — exports `GET` returning the summary `text/plain` document with the locked header + `- [Title](url): description` bullet format from D-09.
- `app/llms-full.txt/route.js` — exports `GET` returning the full-body `text/plain` document with each article's full markdown body inlined under its header.

Depends on Plan 01 because the bullet line format and full-body sections both consume `frontmatter.title`, `frontmatter.description`, and the route shape that Plan 01 stabilizes.
</objective>

**Part A — Add a `mdxBodyToText(raw)` helper function.**

Per user decision on D-10: `llms-full.txt` MUST contain the clean rendered text of each article, NOT raw MDX with JSX wrappers. Shipping raw MDX (which contains `<div className="content-section">`, `<p className="body-text">`, etc.) was the scope reduction the user rejected. The executor MUST strip JSX wrappers and emit clean plaintext.

The planner inspected the actual article files and confirmed these are the JSX wrapper patterns that appear:

- `<div className="content-section">` and `</div>` — block wrappers
- `<div className="steps">`, `<div className="step">`, `<div className="step-num">N</div>`, `<div className="step-title">...</div>`, `<div className="step-desc">...</div>`, `<div>` — step list wrappers
- `<div className="tip-box">`, `<div className="tip-icon">Tip</div>`, `<div className="tip-text">...</div>` — callout wrappers
- `<h2 className="section-heading">...</h2>` — section headings
- `<h3 className="subheading">...</h3>` — sub-headings (if any)
- `<p className="body-text">...</p>` and `<p className="intro">...</p>` — paragraph wrappers
- `<span className="highlight">...</span>` — inline highlights
- `<a href="..." className="...">...</a>` — anchor tags (keep the text, drop the href)
- `<strong>...</strong>`, `<em>...</em>` — inline emphasis (keep the text, drop the tags)

**Approach chosen:** hand-rolled regex pass in `lib/content.js` as a helper function. No new dependencies (`remark` + `remark-mdx` + `strip-markdown` was evaluated and rejected as heavier than necessary for a closed set of wrapper patterns — if new JSX patterns are introduced later, this helper can be extended or replaced with the `remark` pipeline at that point). The user's CONTEXT explicitly listed this as an acceptable option.

Add this helper AFTER `getAllArticles` and BEFORE `getAllArticlesWithBody`:

```js
/**
 * Convert raw MDX body text to clean plaintext by stripping the JSX wrappers
 * used in content/help/**. Preserves paragraph breaks as \n\n.
 *
 * Scope: the closed set of JSX patterns verified by the planner across all
 * 22 articles. If authoring introduces new JSX wrappers, extend this helper
 * or switch to a remark-based pipeline. The acceptance test asserts that
 * the output contains NO `className=` substrings.
 */
export function mdxBodyToText(raw) {
  let text = raw;

  // Headings: <h2 className="section-heading">TEXT</h2> -> TEXT (with blank lines)
  text = text.replace(/<h2[^>]*>([\s\S]*?)<\/h2>/g, '\n\n$1\n\n');
  text = text.replace(/<h3[^>]*>([\s\S]*?)<\/h3>/g, '\n\n$1\n\n');

  // Paragraphs: <p className="body-text">TEXT</p> -> TEXT with trailing blank line
  text = text.replace(/<p[^>]*>([\s\S]*?)<\/p>/g, '$1\n\n');

  // Step lists: extract the inner text. step-num/title/desc are divs we collapse.
  text = text.replace(/<div className="step-num">([\s\S]*?)<\/div>/g, '$1. ');
  text = text.replace(/<div className="step-title">([\s\S]*?)<\/div>/g, '$1\n');
  text = text.replace(/<div className="step-desc">([\s\S]*?)<\/div>/g, '$1\n\n');
  text = text.replace(/<div className="tip-icon">([\s\S]*?)<\/div>/g, '$1: ');
  text = text.replace(/<div className="tip-text">([\s\S]*?)<\/div>/g, '$1\n\n');

  // Inline elements: keep the text, drop the tag.
  text = text.replace(/<strong[^>]*>([\s\S]*?)<\/strong>/g, '$1');
  text = text.replace(/<em[^>]*>([\s\S]*?)<\/em>/g, '$1');
  text = text.replace(/<span[^>]*>([\s\S]*?)<\/span>/g, '$1');
  text = text.replace(/<a [^>]*>([\s\S]*?)<\/a>/g, '$1');

  // Remaining wrapper divs (content-section, steps, step, tip-box, plain div):
  // drop the opening tag and the matching closing tag. Any div, any attrs.
  text = text.replace(/<div[^>]*>/g, '');
  text = text.replace(/<\/div>/g, '');

  // Collapse 3+ newlines to 2 (paragraph break). Trim leading/trailing whitespace.
  text = text.replace(/\n{3,}/g, '\n\n');
  return text.trim();
}
```

```js
export function getAllArticlesWithBody() {
  if (!fs.existsSync(contentDir)) return [];

  const categories = fs.readdirSync(contentDir).filter((f) =>
    fs.statSync(path.join(contentDir, f)).isDirectory()
  );

  return categories.flatMap((category) => {
    const categoryDir = path.join(contentDir, category);
    return fs.readdirSync(categoryDir)
      .filter((f) => f.endsWith('.mdx'))
      .map((filename) => {
        const filePath = path.join(categoryDir, filename);
        const raw = fs.readFileSync(filePath, 'utf-8');
        const { data, content } = matter(raw);
        requireUpdatedAt(data, filePath); // inherited from Plan 01-01 Task 4
        return {
          frontmatter: data,
          content,
          bodyText: mdxBodyToText(content),
          slug: filename.replace('.mdx', ''),
          category,
        };
      });
  });
}
```
